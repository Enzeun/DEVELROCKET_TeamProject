## 🛠️ 3. Git 협업 규칙 (Collaboration Rules)
- 환경 설정 파일 관리: Mobile_RPAsset.asset 등 그래픽 설정 파일은 직접 수정하지 않은 경우 커밋 전 Discard(변경사항 취소)를 진행합니다.
- 씬(Scene) 작업: 동일한 씬을 동시에 수정하지 않도록 작업 전 커뮤니케이션을 진행합니다.
- 커밋 컨벤션:
  - Add: 에셋/클래스 생성
  - Feat: 새로운 기능 추가
  - Fix: 버그 수정
  - Refactor: 코드 리팩토링
  - Asset: 에셋/리소스 추가 및 수정
